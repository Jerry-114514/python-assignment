# 珞珈骑迹账号测试版

需要 Node.js 24。在此目录运行：

```powershell
node build.mjs
node local.mjs
```

用普通浏览器打开 http://127.0.0.1:8787 ，从页面底部进入账号页。输入邮箱后，在启动终端查看一次性验证码。验证成功后可设置用户名和至少 12 个字符的密码。下次登录可直接使用邮箱和密码。更改密码需要先重新验证邮箱。

普通用户从 `luoqier_4` 起按注册顺序编号。测试用所有者邮箱为 `owner@luojia.test`，对应 `luoqier_0`。可在首次注册前设置 `OWNER_EMAIL` 为自己的邮箱。其余三个开发者名额通过 `DEVELOPER_1_EMAIL`、`DEVELOPER_2_EMAIL`、`DEVELOPER_3_EMAIL` 预先绑定。请用测试密码。

本地数据库存放在 `.local-data/`，不会提交。用户名和密码哈希跨重启保留，登录会话和验证码在重启后失效。这个测试版只监听本机，验证码由本机终端展示。正式上线需要接入真实邮件验证和线上账号存储。
